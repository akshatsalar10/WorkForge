1. PRODUCT OVERVIEW & VISION
--------------------------------------------------------------------------------
WorkForge is a multi-tenant team project and operations management platform designed for organizations, project managers, and engineering teams.

Organizations can create dedicated workspaces, invite members with Role-Based Access Controls (RBAC), create projects, assign sequential auto-incrementing tasks (e.g., WEB-1, API-104), collaborate via comments, attach files up to 10MB, track activity streams, receive real-time Socket.IO notifications, view productivity analytics, and search globally using Command Palette keyboard shortcuts (Cmd/Ctrl + K).

3. COMPLETE FEATURE SPECIFICATION (ALL 14 MODULES)
--------------------------------------------------------------------------------
Module 1: Monorepo Foundation & Tech Stack
  - Server: Node.js, Express, TypeScript, Mongoose, Socket.IO, Winston, Zod validation.
  - Client: React, Vite, TypeScript, Redux Toolkit Query (RTK Query), Tailwind CSS, Lucide icons, Recharts.
  - Design Aesthetics: Sleek dark mode palette, glassmorphism card containers, responsive layouts.

Module 2: Authentication & Identity Management
  - JWT access tokens (15m expiry) and HTTP-only refresh tokens (7d rotation).
  - Bcrypt password hashing (10 salt rounds).
  - Registration, login, password reset, email verification, and profile management.

Module 3: Multi-Tenant Organizations & Workspaces
  - Isolated tenant workspaces identified by unique slug URLs (e.g. acme-corp, stark-tech).
  - Organization Member roles: OWNER, ADMIN, MEMBER.
  - Secure tenant guard middleware enforcing strict data boundary isolation.

Module 4: Team Management & Member Assignments
  - Team creation, member assignments, and team lead designations.
  - Interactive Teams page and Team Details roster view.

Module 5: Projects & Access Controls
  - Project key generation (e.g. WEB, API, DES).
  - Project member roles: MANAGER, MEMBER, VIEWER.
  - Project archiving, status filters, and priority tags (LOW, MEDIUM, HIGH, URGENT).

Module 6: Task Management & Auto-Increment Key Generator
  - Human-readable sequential task keys per project (WEB-1, WEB-2, API-1).
  - Subtask checklist with progress percentages.
  - Task priority, assignee allocation, due date tracking, and Label badges.

Module 7: Interactive Drag-and-Drop Kanban Board
  - Interactive @dnd-kit Kanban board with 4 columns: To Do, In Progress, In Review, Done.
  - Optimistic UI updates with automatic server rollback on network errors.

Module 8: Comments & Activity Stream
  - Task discussion thread with Markdown support and relative timestamp formatting.
  - Automated activity stream logs for task creation, status moves, and comment additions.

Module 9: Real-Time Notifications Engine
  - Socket.IO server initialization with authenticated socket handshake.
  - Instant room broadcasts on task assignment, comment additions, and role changes.
  - Animated pulse notification badge and popover dropdown.

Module 10: File Attachments & Asset Storage Provider
  - Multer multipart form upload engine with 10MB size limits and MIME filters.
  - Static asset serving under /uploads with local disk unlinking on file deletion.
  - AttachmentList UI component supporting file previews and direct downloads.

Module 11: Productivity & Team Analytics Dashboard
  - MongoDB Aggregation Engine ($match, $group, $lookup) for velocity throughput.
  - Recharts dashboard rendering Task Status Bar Charts, Priority Breakdown Pie Charts, and Team Workload Capacity tables.

Module 12: Global Search & Command Palette
  - Multi-collection parallel regex search across tasks, projects, teams, and members.
  - Keyboard shortcut Cmd/Ctrl + K launching interactive command palette modal.

Module 13: System Settings & Security Audit Log
  - Data Export JSON engine generating full downloadable workspace backups.
  - Security audit log event timeline for workspace auditing.
  - Danger Zone organization purging requiring exact slug text verification.

Module 14: System Hardening & Documentation
  - Rate limiting middleware (apiRateLimiter, authRateLimiter).
  - Interactive OpenAPI 3.0.3 specification JSON endpoint under /api-docs.
  - System status monitoring page under /health with database latency pings.


4. HOW TO RUN THE PROJECT LOCALLY
--------------------------------------------------------------------------------
Prerequisites:
  - Node.js (v18 or higher)
  - MongoDB (running locally at mongodb://localhost:27017/workforge)

Step 1: Install Monorepo Dependencies
  $ npm run install:all

Step 2: Seed MongoDB Database with Demo Data
  $ cd server && npm run seed

Step 3: Start Server & Client Dev Servers
  - Terminal 1 (Backend Server on http://localhost:5000):
    $ cd server && npm run dev

  - Terminal 2 (Frontend App on http://localhost:5173):
    $ cd client && npm run dev

Step 4: Open Browser
  Navigate to http://localhost:5173 and log in with any demo account (e.g., alex@workforge.com / Password123).
